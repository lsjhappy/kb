# 半导体平台运维知识库

> 这里只放**能带走的东西**：方法、复盘、速查。不放公司机密。

## 为什么建这个

工作上遇到的东西，不写下来就会忘。
写下来了、还分类放好、还能随时搜到 —— 那才是你的能力。

## 怎么用

| 我遇到什么 | 去哪 |
|---|---|
| 命令忘了怎么写 | **01 速查** |
| 听不懂一个词 | **02 术语** |
| 想回忆系统怎么串的 | **03 架构** |
| 想知道"这类问题怎么查" | **04 方法** |
| 刚解决了一个问题 | **05 复盘**（写四行） |
| 想搞懂业务 | **06 业务** |
| 要交东西给别人 | **07 产出** |

## 一条纪律

**每天下班 5 分钟，把一个问题的答案写进 05 复盘。**

不求好看，只求连续。
