# RTD / 派工术语

> 遇到不懂的词就加一行。**一行一个，别写长。**

## 派工核心

| 术语 | 一句话 | 在哪出现 |
|---|---|---|
| **RTD** | 实时派工，系统自动决定"哪批上哪台" | 系统名、Rule 文件 |
| **Lot** | 批次，一次跑的一批晶圆 | 界面、日志 |
| **WIP** | 在制品，全厂还没做完的货 | 报表、监控 |
| **Step** | 工序，路线上的一个步骤 | Route |
| **Recipe** | 配方，机台跑某工序的那套参数 | 机台、规则 |
| **Capability** | 机台能力，这台机能不能做 | 规则筛选 |
| **Dedication** | 专机专用，只能上指定机台 | 规则 |
| **Changeover** | 换型，换 recipe 花的时间 | 排序规则 |
| **Q-time** | 工序间最长等待时限，超了返工或报废 | 规则、告警 |
| **Hold** | 扣留，品质异常被卡住的货 | 状态 |
| **PM** | 预防性维护，机台定期停机 | 机台状态 |
| **Tie-break** | 同分时按什么决先后 | 排序规则 |

## 指标

| 术语 | 一句话 |
|---|---|
| **Cycle Time** | 从投料到完工的总时间 |
| **Move** | 单位时间完成的工序数 |
| **Utilization** | 机台真正在跑的比例 |
| **Yield** | 良率 |
| **Bottleneck** | 瓶颈：产能最低那道工序/机台 |

## 数据同步组件（我们这套）

| 组件 | 干什么 |
|---|---|
| **qtable** | 变更事件表，MES 触发器写进来 |
| **data-sender** | 从 qtable 抽数据发到 Kafka |
| **data-sinker** | 从 Kafka 取数据写目标库 |
| **data-history** | 写同步履历到 MongoDB |
| **admin** | 配置客户端，改 trigger 配置 |
| **aqm** | 低代码平台，配流程 |
| **engine** | 跑 RTD rule 的 Java 程序 |
| **haproxy / VIP** | 负载分发 |

## 记法

> **看不懂的缩写，先记下来，再去问"它在哪出现"。**
> 知道它在哪个界面/哪张表出现，比背定义有用得多。
