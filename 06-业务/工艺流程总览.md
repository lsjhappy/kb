# 半导体工艺流程总览

> 从"流程"切入，不从"概念"切入。**知道货怎么走，比背名词有用。**

## 芯片的一生

```
硅石 → 提纯 → 单晶硅棒 → 切片研磨抛光 → 晶圆 Wafer
   → 前道 FEOL（造晶体管）
   → 中后道（连成电路）
   → 晶圆测试 CP
   → 切割 Dice
   → 封装 → 成品芯片
```

## 三层结构（别把"大类"当"步骤"）

| 层级 | 数量 | 说明 |
|---|---|---|
| **工艺大类** | 8~10 类 | 氧化、光刻、刻蚀、薄膜、注入、扩散、CMP、清洗 |
| **一个循环** | 约 15 道工序 | 光刻一层 + 配套 |
| **完整产品** | 800~1500 道 | 循环 40~80 次 |

## 九大工艺 + 机台

| 工艺 | 干什么 | 机台叫法 | 区域 |
|---|---|---|---|
| **氧化** | 长 SiO₂ | 氧化炉 Furnace | 扩散区 |
| **光刻** | 印图形 | Scanner + Track | 黄光区 |
| **刻蚀** | 刻出图形 | Etcher | 刻蚀区 |
| **薄膜** | 镀新材料 | CVD / PVD / ALD | 薄膜区 |
| **离子注入** | 掺杂质 | Implanter | 注入区 |
| **扩散/退火** | 激活杂质 | 炉管 / RTP | 扩散区 |
| **CMP** | 磨平表面 | CMP 机台 | CMP 区 |
| **清洗** | 去污染 | 湿式清洗机 | 清洗区 |
| **量测** | 测尺寸/缺陷 | CD-SEM、膜厚仪 | 量测区 |

## 一个循环长什么样（15 道）

清洗 → 淀积阻挡层 → 涂胶 → 软烘 → **曝光** → 曝后烘 → 显影 → 硬烘
→ 显影后检测 → 刻蚀 → 去胶 → 清洗 → CMP → 量测 → 缺陷检测

**这只是"一层"。整颗芯片要循环 40~80 次。**

## 派工为什么要管这些

| 工艺特点 | 对派工的影响 |
|---|---|
| 光刻是瓶颈、重入最多 | 优先保瓶颈不待料 |
| 炉管是批量机台 | 要"凑批"，等 or 不等是权衡 |
| 刻蚀/CVD 多腔体 | 同批要走同腔（MultiChamber 规则） |
| 清洗后 Q-time 最紧 | 洗完必须限时进下一道 |
| 量测又贵又慢 | 用抽样（Sampling），不是每批都测 |

## 要盯的五个指标

**WIP ｜ Cycle Time ｜ Move ｜ 瓶颈机台利用率 ｜ Yield**
